# Day 16 - Robot Framework

## What I did
- Installed Robot Framework with SeleniumLibrary
- Wrote login test scenarios (success and failure cases)
- Created custom keywords for reusable login logic (equivalent 
  to Page Object Model pattern in Selenium+Python)

## Robot Framework vs Selenium+Python
- Robot Framework: tabular, keyword-driven syntax, closer to 
  natural language, easier for non-programmers to read/write
- Selenium+Python: full programming language, more flexible for 
  complex logic, requires Python knowledge
- Both use the same underlying browser automation (WebDriver)
- Robot Framework is commonly used in industrial/embedded testing 
  contexts, including automotive
